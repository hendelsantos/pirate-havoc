# Official challenge assets

The original contents of the Jungle Gaming challenge `assets/` directory are imported here by `.github/workflows/import-official-assets.yml` without modifying or deleting licensing information.

`asset-manifest.json` records every imported file with its byte size and SHA-256 digest. The application asset catalog prefers compatible artwork from this directory and falls back to project-owned SVG artwork only when an official file is unavailable.
